# Getting Support

Need help with an AzTeam project? This page explains where to go depending on what you need.

## Quick Guide

| I want to... | Go to |
|---|---|
| Understand how a project works | The repository `README.md` and any `docs/` folder |
| Report a bug | Open an issue with the **Bug report** form |
| Suggest a new feature | Open an issue with the **Feature request** form |
| Ask a usage question | [GitHub Discussions](https://github.com/orgs/azteamaz/discussions) if enabled, otherwise open an issue |
| Report a security vulnerability | Follow [SECURITY.md](SECURITY.md) — **never** use public issues |
| Report a Code of Conduct violation | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Contribute code or docs | Read [CONTRIBUTING.md](CONTRIBUTING.md) |
| Get help with AzTeam hosting, domain or other commercial services | [azteam.az/elaqe](https://azteam.az/elaqe) |

## Before Asking for Help

To get a faster answer, please:

1. Read the project documentation and `README.md`.
2. Search existing [issues](../../issues) — your question may already be answered.
3. Prepare the details we will need: project version, environment (OS, browser, runtime versions), what you expected and what happened, and the exact steps to reproduce.

## Opening an Issue

- Use the matching issue form and fill in every required field.
- One problem per issue.
- Include error messages and logs as text, not screenshots, when possible.
- **Remove passwords, tokens, API keys and personal data** before posting.

## Community Support vs. Commercial Support

Support on GitHub is provided by maintainers and the community on a best-effort basis. There is no guaranteed response time. If you need dedicated or time-critical assistance for AzTeam services, please contact us through [azteam.az/elaqe](https://azteam.az/elaqe).
